# Movie

Feature

   1. Fetch and display movies from TMDb API

   2. Search for movies dynamically

   3. View movie details including title, overview, release date, and poster

   4. Favorite movies and store them locally using Core Data

   5. Error handling and loading indicators

   6. MVVM architecture with Combine


API Endpoints

API_KEY generate from this site : https://www.themoviedb.org/

List Movies: https://api.themoviedb.org/3/discover/movie?api_key=YOUR_API_KEY
